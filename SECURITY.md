# Security

The game runs entirely in the browser: there is no backend and no accounts, and game data stays on the players' devices.
Online games connect phones directly (WebRTC); a public signalling server and a relay are used only to set up the connection.

If you find a security problem, please open an issue **without** sensitive details and ask for a private contact,
or use GitHub's “Report a vulnerability” on this repository if it is enabled.
